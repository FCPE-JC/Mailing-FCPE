Écrire

Un message tel quel (WhatsApp, email) est mis en forme automatiquement ; un texte au format pivot est lu tel quel. Pour reprendre un brouillon exporté, colle-le ici ou ouvre son fichier. Un modèle contient des passages entre crochets, [comme ceci], à remplacer par ton texte.

Tes corrections sont faites : le texte est maintenant écrit au format pivot. Tu peux encore le modifier ici.
