# Lot 5 : user stories validées, v1.0

13 octobre 2026. Rédigé par le fil « Étape 5 : développement », validé par Mat le 13 octobre 2026 à 23 h 28 (« ok pour toutes tes précos »). Lot 5 du découpage (DEC-075) : les sorties (EX-009 à EX-014, EX-028, EX-029), plus les trois ajouts décidés pendant l'essai du lot 4 (DEC-109, DEC-111, DEC-114). Les US commencent à US-021.

## Les user stories

| ID | Titre | Description | Exigences | Critère de fin |
|---|---|---|---|---|

| US-022 | Copier l'email pour Gmail | En tant que rédacteur, je veux copier l'email en un geste et le coller dans Gmail sans perte de mise en forme, afin d'envoyer le mailing depuis mon ordinateur. | EX-009 | Le bouton met dans le presse-papier le code de l'email (`preparerApercu().html`, sans étiquettes, DEC-104), en HTML et en texte, par la méthode prouvée au test T1 ; si le navigateur ne le permet pas, l'email est sélectionné pour un Ctrl+C (ou ⌘+C) avec une phrase qui le dit (US-003) ; un test vérifie que le contenu copié est exactement le code de l'aperçu sans étiquettes. |

## Questions pour Mat et réponses

Mat a suivi les cinq préconisations.

1. **Deux demandes de fusion, deux essais ?** D'abord les sorties (US-021 à US-028), puis les trois ajouts du lot 4 (US-029 à US-031). *Je préconise oui : chaque essai reste court, et tu peux faire tout le parcours jusqu'à Gmail dès la première.*
2. **Exporter le brouillon** : le copier ET proposer un fichier à télécharger ; « Reprendre » accepte le collage ET l'ouverture du fichier ? *Je préconise oui pour les deux : la copie sert à l'envoyer sur WhatsApp à soi-même, le fichier à le garder sur l'ordinateur.*
3. **Copie pour Gmail impossible** (navigateur trop ancien) : l'email est sélectionné pour un Ctrl+C, avec une phrase qui le dit ? *Je préconise oui : c'est le repli du test T1, qui a donné le même rendu.*
4. **Avertissement avant de recharger** : seules la copie pour Gmail et l'export du brouillon comptent comme « mis à l'abri » ; une copie WhatsApp ou une image, non ? *Je préconise oui, comme le dit EX-029 : une copie pour relecture n'est pas l'envoi.*
5. **Prompt IA** : mis à jour pour le surtitre de 60 caractères dès la première demande, et pour les nouvelles pastilles et le type Signature avec la seconde ? *Je préconise oui.*
