# Lot 5 : modifier le texte d'un bloc depuis l'écran Vérifier

Question de Mat du 13/10/2026 (23 h 07) : modifier le texte depuis l'écran Vérifier, sans aller-retour avec l'écran Écrire. Propositions validées le 13/10/2026 (23 h 08, « OK pour tes 2 précos »). À reprendre dans les US du lot 5 ; DEC-111.

- **Forme (Q1)** : un champ « Texte du bloc » dans le panneau qui s'ouvre au toucher d'un bloc, pour un paragraphe, une accroche, une liste, une date, un encadré, la clôture et la signature. La modification réécrit le pivot de l'écran Écrire, comme les autres corrections (DEC-103), et « Annuler » la défait.
- **Écarté** : la frappe directe dans l'aperçu, qui est le code exact copié et qui serait peu fiable sur téléphone.
- **Côte à côte sur PC** : reste prévu au lot 6 (question 4 du lot 2).
- **Quand (Q2)** : au lot 5, avec les pastilles (DEC-109).
